# 07 — Stacks, Queues and Heaps

## Stacks
LIFO structure; useful for nested structure, parsing, undo-like state and monotonic processing.
- Balanced parentheses
- Expression evaluation
- Next greater/smaller element
- Largest rectangle in histogram
- Monotonic stack invariants

## Queues and deques
FIFO structure; useful for BFS and sliding-window processing.
- Queue using stacks
- Deque operations
- Sliding-window maximum with a monotonic deque
- 0–1 BFS (graph module)

## Heaps / priority queues
- Min-heap and max-heap
- Push/pop O(log n), top O(1)
- Top-K, k-way merge and scheduling
- Lazy deletion and stale entries in graph algorithms
