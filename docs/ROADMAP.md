# Learning Roadmap

This roadmap is competency-based. The month ranges are planning estimates for a consistent learner, not deadlines. Do not advance solely because a calendar block ended.

## Stage 0 — Engineering foundations (2–4 weeks)
C++20, STL, memory, debugging, integer safety, asymptotic analysis, proof basics.
**Gate:** implement common containers/algorithms and analyse their costs without notes.

## Stage 1 — Core linear problem solving (6–10 weeks)
Arrays, strings, hashing, sorting, binary search, two pointers, sliding windows, prefix sums, difference arrays, linked lists, stacks, queues, heaps.
**Gate:** solve mixed easy/medium problems without being told the pattern; explain invariants.

## Stage 2 — Recursive structures and greedy (6–10 weeks)
Recursion, backtracking, trees, BSTs, traversals, tree properties, greedy proofs.
**Gate:** derive recursive states, prove greedy choices and implement standard tree algorithms.

## Stage 3 — Graphs and dynamic programming (10–16 weeks)
Graph modelling, BFS/DFS, DSU, topological order, shortest paths, MST, SCC, bridges, DP state design and common DP families.
**Gate:** model unseen problems as graphs or DP and justify the model and transitions.

## Stage 4 — Advanced toolkit (12–20 weeks)
Fenwick and segment trees, sparse tables, tries, KMP/Z, suffix structures, number theory, flows, geometry, FFT/NTT and optimisation DP.
**Gate:** recognise when advanced tools are justified by constraints and implement core versions reliably.

## Stage 5 — Competitive programming development (ongoing)
Regular contests, virtual contests, upsolving, topic-based rounds, rating-band practice and editorial review.
**Gate:** consistent independent performance across several contests, not one peak result.

## Weekly operating system
- 4 focused learning/practice sessions.
- 1 mixed-topic session with no topic labels.
- 1 timed contest or virtual contest followed by upsolving.
- 1 review session: re-solve old problems, update notes and plan next week.

## A 3-hour session
- 30 min: concept and proof.
- 75 min: focused problems.
- 60 min: one independent challenge.
- 15 min: review and spaced-repetition scheduling.

## Rating progression (optional diagnostic)
Treat rating bands as rough practice filters, not guarantees:
- Below 1200: implementation, basic maths, arrays, sorting and constructive basics.
- 1200–1600: standard patterns, binary search, greedy, basic trees/graphs/DP.
- 1600–1900: non-obvious modelling, stronger proofs, graph/DP combinations.
- 1900–2200: advanced structures, optimisation and multi-step reasoning.
- 2200+: deeper specialisation, speed, accuracy and originality.

Do not rush rating bands. A strong foundation is the multiplier.
