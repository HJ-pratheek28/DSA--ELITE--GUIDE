# 11 — Graph Algorithms

**Goal:** model relationships as vertices and edges, then choose algorithms from graph properties and constraints.

## Representation
- Directed / undirected, weighted / unweighted
- Adjacency list, matrix and edge list
- Connected components and degree
- Multi-edges, self-loops and disconnected graphs

## Traversal and structure
- BFS and DFS
- Cycle detection
- Bipartite checking
- Topological sorting
- Strongly connected components
- Bridges and articulation points

## Connectivity and paths
- Disjoint Set Union (DSU)
- Minimum spanning tree: Kruskal and Prim
- BFS for unweighted shortest paths
- Dijkstra for non-negative weights
- Bellman–Ford for negative edges and negative-cycle detection
- Floyd–Warshall for all-pairs paths on small dense graphs

## Advanced
- DAG dynamic programming
- Eulerian paths and circuits
- Maximum flow / minimum cut
- Bipartite matching
- Lowest common ancestor and tree algorithms (see trees)

## Practice ladder
- Number of Provinces / connected components
- Flood Fill / grid BFS
- Course Schedule / topological sort
- Bipartite Graph
- Network Delay Time / Dijkstra
- Cheapest Flights Within K Stops
- Redundant Connection / DSU
- Minimum Spanning Tree
- Critical Connections / bridges

## Exit test
Select a graph representation and traversal, handle disconnected graphs, and justify why the shortest-path algorithm's weight assumptions hold.
