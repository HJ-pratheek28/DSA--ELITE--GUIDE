# 10 — Greedy Algorithms

**Goal:** identify when a locally chosen action can be part of a globally optimal solution.

## Core ideas
- Sorting by a meaningful key
- Interval scheduling and merging
- Earliest finish / deadlines
- Resource allocation and priority queues
- Huffman coding intuition
- Exchange arguments
- Staying-ahead proofs
- Greedy choice property and optimal substructure
- Matroids as a deeper unifying framework

## Proof discipline
A greedy solution is not justified by “choosing the best now seems right.” Identify an optimal solution and show how an exchange transforms it to include the greedy choice without making it worse.

## Practice ladder
- Assign Cookies
- Non-overlapping Intervals
- Meeting Rooms / Meeting Rooms II
- Jump Game
- Gas Station
- Minimum Number of Arrows
- Task Scheduler
- Huffman coding exercise

## Exit test
For each proposed greedy algorithm, state its choice rule and provide a correctness proof or a counterexample.
