## Patterns to watch

- Misreading constraints or edge cases
- Choosing a data structure before identifying required operations
- Incorrect loop invariant or off-by-one boundaries
- Confusing node depth and tree height
- Forgetting integer overflow
- Assuming greedy choices without proof
- Defining a DP state that does not contain enough information
- Ignoring disconnected graph components
- Passing samples but not adversarial tests
