# 06 — Linked Lists

**Goal:** reason about pointer changes and node ownership without losing nodes or creating cycles.

## Concepts
- Singly and doubly linked lists
- Dummy/sentinel nodes
- Pointer rewiring and local invariants
- Fast/slow pointers
- Cycle detection and cycle entry
- Reversal: iterative and recursive
- Merge two sorted lists
- Remove / insert around positions
- Intersection of linked lists
- Reordering and splitting lists

## Implementation discipline
Draw the nodes and arrows before changing links. Save the next pointer before overwriting a link. Define what each pointer represents at every step.

## Practice ladder
- Reverse Linked List
- Middle of the Linked List
- Linked List Cycle / Cycle II
- Merge Two Sorted Lists
- Remove Nth Node From End
- Swap Nodes in Pairs
- Reorder List
- Reverse Nodes in k-Group (advanced)

## Exit test
Reverse a list, detect a cycle, merge sorted lists and explain pointer invariants for each.
