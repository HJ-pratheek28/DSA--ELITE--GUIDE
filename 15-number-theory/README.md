# 15 — Number Theory

## Core sequence
1. Divisibility, primes and factorisation
2. Sieve of Eratosthenes and smallest prime factor
3. Euclidean algorithm and extended GCD
4. Modular arithmetic and safe multiplication
5. Binary exponentiation
6. Modular inverses and linear congruences
7. Euler totient and Fermat/Euler theorems
8. Chinese remainder theorem
9. Combinations modulo a prime
10. Linear sieve and multiplicative functions

## Advanced directions
- Primitive roots
- Discrete logarithm
- Möbius function and inversion
- Diophantine equations
- Pollard Rho / Miller–Rabin (probabilistic/primality toolkit)

## Important cautions
- A modular inverse exists only when the value and modulus are coprime.
- Fermat's little theorem in the common inverse form requires a prime modulus.
- Avoid overflow in multiplication before taking modulo.
- Distinguish exact division from modular division.

## Exit test
Implement sieve, gcd, extended gcd and modular exponentiation; explain the conditions for a modular inverse.
