# 09 — Trees and Binary Search Trees

**Goal:** reason recursively about hierarchical structures and exploit BST ordering when valid.

## Foundations
- Root, parent, child, sibling, leaf, depth, height and subtree
- Binary tree properties and representations
- Preorder, inorder, postorder and level-order traversal
- Recursive and iterative traversal
- Height, diameter, balance and path problems

## BST
- Search, insertion and deletion
- Inorder traversal gives sorted order
- Validate BST using bounds, not only parent-child comparisons
- Lowest common ancestor
- Kth smallest / successor / predecessor

## Advanced tree techniques
- Tree DP and rerooting intuition
- Binary lifting for ancestor queries
- Euler tour / subtree flattening
- Heavy-light decomposition (advanced)
- Centroid decomposition (advanced)

## Practice ladder
- Maximum Depth / Minimum Depth
- Invert Binary Tree
- Level Order Traversal
- Diameter of Binary Tree
- Balanced Binary Tree
- Path Sum I / II / III
- Validate BST
- Lowest Common Ancestor
- Binary Tree Maximum Path Sum
- House Robber III

## Exit test
Explain traversal order, solve a tree DP problem and validate a BST using a correct global invariant.
